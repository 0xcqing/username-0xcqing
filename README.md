This program sends the account's own make.fun username, `0xcqing`, as the single-word entry and nothing else. It writes that word as UTF-8 to `entry.txt` inside the output directory, then reads it back and verifies the bytes match exactly before printing the path, handle, character count and byte count.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

On Windows PowerShell:

```powershell
$env:MAKEFUN_OUTPUT_DIR="./out"; node main.ts
```
